# Контрольная работа №1
Задача: Создать техническую документацию по использованию редактора Brackets (Phoenix Code)

``` Структура документа: ```
- Титульный лист
-	Оглавление
-	О самом Brackets (что это за программа, как используется)
-	Подробная инструкция по установке (со скриншотами)
-	Как пользоваться самим редактором (знакомство с интерфейсом)
-	Установка плагинов/расширений
- Горячие клавиши

``` Чек-лист: ```
-	Правильно оформленные списки
-	Иллюстрации, встроенные в текст (желательно, с подписями)
-	Сноски (3-4 на документ)
-	Заголовки (1-3 уровней)
-	Автоматически собираемое оглавление
-	Ссылка (на установочную страницу и др.)
-	Проверьте поля (должны быть обычные)
-	В верхнем колонтитуле название документа, внизу нумерация страниц
-	Итоговая работа сохранена как pdf (все ссылки с сноски должны в нем работать)
