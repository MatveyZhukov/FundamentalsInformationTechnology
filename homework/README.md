# Домашние задания

Одно домашнее задание — одна папка `NN-<тема>`: номер двумя цифрами и тема английским словом.
Когда задание выдано, преподаватель дописывает строку в таблицу ниже. Имя папки берите из таблицы.

| Папка | Задание |
|---|---|
| [`00-example`](00-example/README.md) | образец оформления сданного ДЗ |
| [`01-boolean-conditions`](01-boolean-conditions/README.md) | ДЗ 1. Главы 2.1–2.2: логический тип и составные условия, 12 задач из задачника |
| [`02-if-elif-else`](02-if-elif-else/README.md) | ДЗ 2. Главы 2.3–2.5: диапазоны, `if` / `elif` / `else`, вложенные условия, 14 задач |

## Что лежит в папке ДЗ

| Файл | Что в нём |
|---|---|
| `README.md` | что задано, список файлов, проверка: ввод и вывод |
| `task_01.py`, `task_02.py`, … | по одному файлу на задачу |
